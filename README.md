# 公報番号リンク作成アプリ

Excelまたは直接入力した公報番号からEspacenetとJ-PlatPatへのリンクを作成するStreamlitアプリです。Excel入力では元のExcelを変更せず、リンク列を追加した別ファイルをダウンロードします。直接入力では公報番号とリンク列を含む新しいExcelファイルをダウンロードできます。

## 起動方法（Windows PowerShell）

プロジェクトフォルダで次を実行します。

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

起動後に表示されるURLをブラウザーで開きます。通常は `http://localhost:8501` です。終了するときはPowerShellで`Ctrl+C`を押します。

## 使い方

1. 「入力方法」で「Excelファイル」または「直接入力」を選びます。
2. Excelの場合は`.xlsx`ファイルをアップロードし、対象シートと公報番号列を選択します。列名が「公報番号」の場合は初期選択されます。
3. 直接入力の場合は、公報番号を1行に1件ずつ入力または貼り付けます。空行は無視されます。
4. 画面でリンクを確認し、「リンク付きExcelをダウンロード」を選択します。
5. Excel入力では元ファイル名に`_with_links`を付けた名前で保存され、リンク列は表の右端に追加されます。直接入力では`公報番号_with_links.xlsx`として、公報番号とリンク列を含む新しいファイルを作成します。リンクセルの表示文字列は「Espacenet で開く」「J-PlatPat で開く」です。

## リンクの対象範囲

- Espacenetは、形式を解析できる国コード付き公報番号を使って検索リンクを作成します。
- J-PlatPatは、日本の公開・公表公報、特許登録公報、および外国のWO、US、EP、CN、KR、GB、DE、DD、FR、CH、CAの対応種別にリンクを作成します。
- 対象外の国・種別（例: TW）や解析できない値は、該当するリンク欄が空欄になります。
- URLの番号形式や国別の補正ルールはアプリ画面の「リンク作成ルール」を参照してください。
- リンク先に文献が収録されていない場合や、各サービス側の一時的な制限がある場合、検索結果が表示されないことがあります。

## 注意事項

- Excelの読み込み結果と生成結果はセッション単位の`st.cache_data`に保存され、有効期限は1時間です。別の利用者のセッションとは分離され、セッション切断時に破棄されます。
- Streamlitのアップロード上限は、設定変更がない場合1ファイルあたり最大200 MBです。大きなファイルの同時処理では、Community Cloudの共有リソース制限により処理が遅くなったり、アプリが停止したりすることがあります。
